# Legacy closeout

September 5, 2026. This standalone skill is unmaintained. No new release line,
security response or ongoing support is promised. The source and MIT license
remain available for reference and forks.

Back up `memory/observations.md`, `memory/reflections.md`, and useful provenance
privately. Inspect the host's **current** scheduler and remove only jobs created
for this skill (historically `observer-memory` and `reflector-memory`). Job names
and IDs must be verified; do not delete native memory dreaming or generic
observer jobs owned by another component.

Remove the installed `skills/observational-memory` directory and only its added
startup-reading instructions from `AGENTS.md`/`HEARTBEAT.md`. Preserve native
`MEMORY.md`, `USER.md`, daily notes and unrelated skill instructions. Restart
affected sessions and confirm the skill and its jobs are no longer loaded.

The Python OM core, its packages and relays are separate installations. If also
installed, follow the [core migration guide](https://github.com/intertwine/observational-memory/blob/main/docs/legacy-migration.md).
Sharing reviewed files remains possible; seamless cross-vendor memory is not
claimed as a native replacement. No memory data is deleted by this docs closeout.
